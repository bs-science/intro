# BS Spectrum Lab

2026년 복성고 과학 과제연구의 실험 정보, 데이터 및 스펙트럼 분석 도구를 공유하는 홈페이지입니다.

## 주요 내용

- NaCl 농도에 따른 mCP 용액의 가시광 흡수 스펙트럼 연구 개요
- 실험 변인과 측정·분석 과정
- Spectrum Analyzer 설치 파일 및 배포 정보
- 연구 자료와 수정 요청 링크
